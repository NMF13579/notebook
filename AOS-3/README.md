# AOS-3 (Синтез и проектирование)

## Назначение
Папка `AOS-3` является **рабочей областью (workspace)** для проектирования проектной документации.
Ее цель — собирать, систематизировать и объединять материал из официальной утверждённой базы знаний (`/docs`), а также из чатов и обсуждений.

Созданная здесь документация по разработке AOS (своего рода "продуктовая папка") будет впоследствии применена как **активный источник знаний** в новом целевом репозитории.

## Правила для ИИ-агентов
- Материалы внутри `AOS-3` имеют статус `DRAFT` и **не заменяют** официальный baseline, который лежит в `/docs/`.
- Вы можете использовать эту директорию для генерации новых структур, объединения идей и черновой работы перед экспортом в целевой репозиторий.
