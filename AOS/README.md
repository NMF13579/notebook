# AOS Deliverable Package

* **AOS/** является будущим deliverable package (пакетом готовой документации для передачи implementation agent).
* Документы создаются и разрабатываются в **workspace/**.
* После полного завершения работы и принятия документы переносятся в **AOS/**.
* **docs/** остаётся текущей knowledge baseline проекта (исходной базой знаний).
* **archive/** содержит только исторические материалы.
